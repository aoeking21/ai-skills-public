# 摄影姿势融合 V1.0

状态：Fusion Design  
分支：`fusion/pose-gallery-photography-v1`  
目的：把姿势图库接进现有写真系统，不复制图库图片，不新增一个权威入口，不打破 `docs/photography-image-asset-inventory-v1.0.md` 已确认的单一事实源设计。

## 1. 融合的是什么

本次融合三样东西：

1. 新技能 `skills/pose-gallery-director`：姿势、服装、人像参考检索与取图。
2. 图库来源：日本原版 Gia（@giaaibusi）ai-pose-gallery，中文镜像 anhao/ai-pose-gallery-zh。姿势 1,439 条（288 组乘 5 角度），服装 1,407 条，人像 1,499 条。
3. 现有写真系统：`skills/aoeking-xiezhen-director`（身份与连续性）、`image-generation/female-portrait-director`（风格与路线）、`skills/portrait-master-director`（通用总控与质量门）。

融合方式是路由，不是复制。姿势技能不复制三位导演的合同正文，不复制图库图片，不把姿势写进人物 Profile。调用时按任务加载必要模块，与盘点报告第 7 节“新总 Skill 的目标边界”一致。

## 2. 姿势在系统里的位置

姿势是可变摄影元素，落在统一优先级第 7 层之前的一个动作层：

1. 安全、成年和授权。
2. 用户本轮明确任务、数量、画幅、保留项和显式修改项。
3. 人物身份不变量。
4. 已确认的连续项目 Profile。
5. 解剖、重力、衣料、风、水和环境物理。
6. 摄影事件与空间关系。
7. 姿势动作（新）。
8. 构图、光影、美颜、镜头和风格。

接线点在 `aoeking-xiezhen-director` 执行顺序第 5 步之后、第 7 步之前：主摄影事件确定后、机位设计前插入姿势选择。姿势必须由事件推导，或至少与事件因果一致。

## 3. 一次融合任务的标准流程

1. 定任务模式与身份来源。身份保留任务先走身份锁定，姿势技能不得先于身份锁定输出成片。
2. 中文关键词检索姿势，默认安全模式，给最多五个候选，等用户挑一张。
3. 只拉选中的一张原图，核对编号与名称一致。
4. 把姿势写进摄影事件，推导重心、手部反应、视线、表情与衣料受力。
5. 需要换角度时，用同一姿势编号的另一角度记录，不换姿势。
6. 风格路线仍按 `female-portrait-director` 的复合指纹选，姿势不单独决定路线。
7. 三合一参考时按人像加服装加姿势组合，每张参考图先分角色：identity、wardrobe、pose。
8. 出图前走 `portrait-master-director` 质量门，姿势参考图只校验动作、解剖与摄影真实感，不携带身份权威。

## 4. 与盘点报告已确认冲突的关系

- P0-01 同名 Skill 碰撞：新技能名 `pose-gallery-director` 经全仓库检索确认无碰撞，见第 6 节验收。
- P0-02 双份实现：本技能只有 `skills/` 一份 canonical 实现，不设发行镜像。`image-generation/` 下不另存副本。
- P1-01 身份优先级不统一：姿势落在身份不变量之后，融合合同明确写死这一顺序，风格模块不得用姿势静默覆盖身份。
- P1-02 美颜语义冲突：不涉及，姿势技能不定义美颜术语。
- P1-03 构图锁定冲突：Composition 为 `preserve` 的任务禁止引入新姿势。
- P1-04 光影锁定冲突：Lighting 为 `preserve-source` 的任务禁止因姿势改主光方向。
- P1-06 历史成片污染规则层：姿势参考图是素体线稿，role 固定为 `pose`，不进入人物真值层，不进入全局规则层。
- P1-07 人物专属规则混入通用总库：姿势技能不收录任何人物专属锚点，人物 Profile 仍由各导演技能按原机制隔离。
- P1-08 外部复用边界：图库许可未覆盖批量分发，因此本仓库不收录图片与目录 JSON，只收录检索脚本与合同。图片按需单张从上游拉取。

## 5. 不做的事

- 不把 1,439 张姿势图、服装图、人像图提交进本仓库。
- 不把目录 JSON 提交进本仓库。检索脚本首次运行时下载到本地缓存。
- 不修改 `aoeking-xiezhen-director`、`female-portrait-director`、`portrait-master-director` 的 SKILL.md 正文，只通过新技能的融合合同引用它们。
- 不把一次任务的姿势、服装、体型参数写回人物 Profile。
- 不在未成年人任务里放开成人系姿势。

## 6. 验收标准

- 全仓库不存在未声明的重复 Skill name，`pose-gallery-director` 唯一。
- `skills/pose-gallery-director/manifest.json` 有效 JSON，files 列表与实际文件一致。
- 检索脚本在全新缓存下能跑通“坐姿”检索，并只拉取用户选中的一张原图。
- 默认检索不返回性感系与双人缠绵记录。
- 根 README 已登记新技能，目录树一致。
- 本次修改可追溯到本文件与盘点报告的问题编号，不删除历史资料。

## 7. 回滚

回滚时删除 `skills/pose-gallery-director/`、本文件，并在根 README 里移除登记行。既有三位导演技能、图库来源与私人影集无需恢复。
